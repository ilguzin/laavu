# Laavu

Долгоживущие рабочие сессии на своём сервере. Laavu ставится на VPS или своё железо и даёт с ноутбука и телефона работать с CLI-агентами (Claude Code и другими), терминалами и файлами. Сессии — это tmux: закрыл браузер, агент продолжает работать, открыл с другого устройства — вернулся в ту же сессию.

Laavu (финск. «ла́аву») — открытый навес в лесу, которым пользуется любой, а порядок держат сами путники.

> Проект на ранней стадии. Подписанных релизов пока нет, ставить можно из исходников. Интерфейс и документация — на русском.

## Что умеет

- Сессии агента и терминала в tmux на сервере, переживают закрытие браузера и перезапуск демона, после перезагрузки сервера поднимаются из снимка (`claude --resume`).
- Статусы сессий по хукам Claude Code: «работает», «ждёт ответа», последнее действие агента. Пуш на телефон, когда агент ждёт ответа.
- Файлы рядом с терминалом: дерево, просмотр Markdown, PDF, картинок и HTML, правка с проверкой версии, «что изменилось» по git, загрузка с телефона.
- Телефон как полноценный вход: PWA, полоса клавиш, прокрутка свайпом.
- Вход по passkey, без паролей.
- Изоляция агентов: у каждого свой системный пользователь, лимиты systemd, свои порты и правила nftables. Демон работает без root.
- Установка одной командой на сервере или с ноутбука по ssh, обновления с проверкой подписи и откатом.

## Как устроено

```
браузер ── HTTPS ── Caddy ── laavud (демон) ── laavud worker (по одному на агента) ── tmux ── claude, shell
```

- **`laavud`** — демон, воркер агента, хуки Claude Code и tmux. Клиент (Preact, xterm.js, CodeMirror) вшит в бинарник.
- **`laavu`** — утилита владельца сервера: установка, агенты, обновления, проверка изоляции, диагностика.

Подробно — в [`docs/architecture.md`](docs/architecture.md).

## Установка

Нужен сервер на Ubuntu 24.04 или новее, доступ по ssh с `sudo` и, для публичного адреса, домен, указывающий на сервер.

Собрать из исходников (Go 1.26+, Node 22+):

```sh
make web build
```

Поставить с ноутбука на сервер:

```sh
bin/laavu install --ssh ubuntu@IP --domain laavu.example.com --email you@example.com --agent main --install-claude
```

Или скопировать `bin/laavu` и `bin/laavud` на сервер и запустить там `sudo ./laavu install …` с теми же флагами, кроме `--ssh`. В конце установка печатает ссылку регистрации первого passkey. Без домена (`--host ИМЯ`) Laavu работает на портах 8443 и 8444 с внутренним сертификатом Caddy — так удобно пробовать на ВМ или в tailnet.

Все команды и флаги — в [`docs/arch-laavu.md`](docs/arch-laavu.md).
